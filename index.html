我们处理的数据

遇见仅在你主动使用相关功能时处理以下数据：

  • 你输入的随手记录、待办和选择保存的网页文字；
  • 你选择同步的微信读书划线、书籍标题和想法；
  • 你填写的微信读书 Skill API Key；
  • 你配置的 Obsidian 路径、本地 txt 文件名与模块、主题等偏好；
  • 你主动通过系统选择器授权的本地 Markdown / txt 文件内容和浏览器文件句柄。

数据如何保存与传输

  • 想法、设置和待办快照保存在当前设备的 Chrome 本地存储中。
  • 经授权的本地文件句柄保存在当前设备浏览器的 IndexedDB 中，仅用于读写你已选择的文件或文件夹。
  • 遇见不运营自建数据服务器，也不出售、出租或将数据提供给广告、分析或数据经纪服务。
  • 只有当你开启微信读书同步时，扩展才会把 API Key 用于请求微信读书 Skill Gateway，以获取你授权范围内的阅读笔记。
  • 只有当你选择保存到 Obsidian 时，扩展才会通过 Obsidian URI 将内容交给当前设备上的 Obsidian 客户端。

数据控制

你可以关闭微信读书同步、删除想法和待办、导出本地数据，或移除扩展以停止继续使用。迁移到另一台设备时，需要重新授予本地文件访问权限。

第三方服务

微信读书同步与 Obsidian 保存均由你主动开启。使用这些功能时，也应遵守对应服务的条款和隐私政策。
